# DrawAndGuessMod 模型预览

双击模组根目录下的 `launch-model-preview.cmd`。脚本会启动仅监听 `127.0.0.1` 的本地服务，并自动打开浏览器：

```text
http://127.0.0.1:8765/
```

页面包含两部分：

- 搜索卡牌 ID，查看原始卡图以及保留原始颜色、缩放到 32×32 后的模型输入。
- 选择或拖入图片，并列查看当前384维特征、DINOv2视觉特征和二者融合后的三组 Top 3。
- 拖动DINOv2权重滑条，实时重新检索并比较不同融合比例。

首次运行语义预览前安装开发依赖：

```powershell
python -m pip install torch torchvision timm
```

默认通过 `timm` 加载Meta DINOv2的 `vit_small_patch14_dinov2.lvd142m`（ViT-S/14，224×224 输入，384维），与游戏内 ONNX 模型使用相同预处理。第一次启动会下载模型权重，并为全部卡图建立一次视觉向量缓存；控制台会显示进度。缓存位于 `Scripts/Preview/.semantic-cache/`，之后启动会直接复用。上传图片始终只发送给本机服务，不会上传到外部模型API。

上传测试时应使用绘画区域本身。完整卡牌截图包含卡框、标题和描述文字，而游戏内分类器只读取画布，因此两者结果会不同。

结果指标：

- `欧氏距离`：游戏实际用于排序的 384 维特征距离，越小越接近。
- `匹配度`：`1 - distance / 2` 的启发式百分比，只用于直观显示。
- `DINOv2余弦相似度`：上传画作与卡图的归一化视觉向量点积，越大越接近。
- `融合 z-score`：分别标准化负欧氏距离和DINOv2相似度后，按页面滑条加权的结果。

匹配度、DINOv2相似度和融合分数均未通过带标签的玩家绘画测试集校准，不是统计意义上的真实准确率。

关闭启动预览器的命令行窗口，或在窗口内按 `Ctrl+C`，即可停止本地服务。
